# Praktikum Tkinter Sesi 11 - Pendaftaran Kegiatan Mahasiswa

## Tujuan
Membangun aplikasi GUI menggunakan Python Tkinter dengan memanfaatkan berbagai widget, event handling, validasi input, menu, dan dialog.

## Fitur
- Input nama menggunakan `Entry`.
- Pemilihan program studi menggunakan `Combobox`.
- Pemilihan jenis kelamin menggunakan `Radiobutton`.
- Pemilihan kegiatan menggunakan `Checkbutton`.
- Input alasan mengikuti kegiatan menggunakan `Text`.
- Tombol `Submit` dan `Reset`.
- Ringkasan pendaftaran ditampilkan pada area informasi (`Text`).
- Notifikasi menggunakan `Messagebox`.
- Menu `File` dengan pilihan `Exit/Keluar`.
- Jendela `About` menggunakan `Toplevel`.
- `Listbox` untuk menampilkan pilihan kegiatan.
- Validasi nama tidak boleh kosong.
- Menu `Bantuan` membuka jendela `About`.
- Event keyboard `Enter` menjalankan `Submit`.
- Antarmuka dirapikan dengan `Frame` dan geometry manager (`pack`/`grid`).

## Cara Menjalankan
1. Pastikan Python 3 terpasang.
2. Jalankan perintah:
   ```bash
   python3 main.py
   ```

## Pengumpulan
Unggah berkas `main.py`, `README.md`, dan screenshot aplikasi ke repository GitHub bernama `praktikum-tkinter-sesi-11`.
